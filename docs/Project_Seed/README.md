## 產品需求與 WHY

Project Seed 保存產品要解決的問題、使用情境、期望行為與品質要求，以及這些需求的原因。完整產品目標與願望保留在此；目前交付範圍由工作狀態記錄。

| 文件 | 用途 |
| --- | --- |
| [Core Requirements rc.6](GraspPortable-Core-Requirements-v1.0.0-rc.6.md) | 現行 WHAT／WHY、產品語義及完成判準 |
| [最早可查來源](../Reference/Originals/README.md) | 兩份 rc.1 原文及來源限制，供核對原始意圖 |

語法、資料權威與可攜性若直接決定使用者得到的行為，仍屬產品需求。框架、模組實作、開發流程與驗證方法由 [Engineering](../Engineering/README.md) 承載；實際技術決策見 [Technology Selection](../Engineering/Decisions/Technology-Selection-v1.1.1.md)，目前授權見 [工作狀態](../EXECUTION-STATE.md)。

使用者最新明確決策優先於現行文件。原始文件保存來源事實；後續已接受的需求修正仍有效。Prototype 報告中的實作及量測只描述其原版本。
