# Implementation contract

The two Project_Seed core documents are authoritative. This file only records working module agreements.

- Domain types: `src/domain/model.ts`. Identifiers match `[A-Za-z_][A-Za-z0-9_.-]*`.
- Note declaration: a standalone line `@name = "JSON string with {other.name} interpolation"`. Declaration lines outside fenced/inline code only. Inline value reference: `{{name}}`. Escaping literal braces in templates uses `{{` / `}}`; reference syntax is not interpreted inside code fences or inline code.
- Structured records: identifier `${collection}.${name}.${field}`. String fields support the same interpolation. Records live in DB, never one file per record. A view is a fenced `grasp-query` block containing `{"collection":"aura","where":{"field":"element","equals":"fire"}}` (where optional); render a table.
- Domain exports from `src/domain/knowledge.ts`: `parseNote(note: Note): ParseResult`, `buildKnowledge(notes: Note[], records?: StructuredRecord[]): ParseResult`.
- Calculation exports from `src/domain/graph.ts`: `class ValueGraph { update(parsed: ParseResult, revision: number): RuntimeResult }`, with persistent cache and incremental invalidation. No browser, Node, editor or DB dependency.
- Editor exports from `src/editor/editor.ts`: `createEditor(parent: HTMLElement, options: { onChange(markdown:string):void; onNavigate(name:string):void; onFindReferences(name:string):void }): EditorAdapter`. Adapter methods `setDocument(markdown:string)`, `getDocument():string`, `setRuntime(result:RuntimeResult, records?:StructuredRecord[]):void`, `focusRange(from:number,to:number):void`, `setMode(mode:'live'|'source'):void`, `destroy():void`. Do not emit onChange on setDocument. Keep IME/undo local.
- API JSON camelCase. `GET /api/workspace`; `POST /api/workspace/open {path,create?,name?}`; `PUT /api/notes/:id {title,markdown,revision}`; `POST /api/notes {title,markdown}`; `DELETE /api/notes/:id {revision}`; `PUT /api/records/:id {record,revision}`; `DELETE /api/records/:id {revision}`; `PUT /api/settings {settings}`. Mutations return full committed WorkspaceSnapshot; conflicts HTTP 409. No DB updates from export files except explicit import.
- Exchange: `GET /api/export` returns downloadable Markdown (all notes plus versioned metadata/records); `POST /api/import/plan {markdown}` returns ImportPlan; `POST /api/import/apply {token,workspaceRevision}` returns snapshot; `GET /api/history` and `POST /api/history/:id/restore {workspaceRevision}` for recovery.
- API exports `createApi(options?:{defaultPath?:string}): {handle(req:IncomingMessage,res:ServerResponse):Promise<boolean>;close():void}`. `server/main.ts` hosts static files/Vite; `src/app` handles UI commands, while `src/runtime` owns the worker bridge. Tests address these boundaries independently and through production E2E.
- Default workspace `workspaces/Welcome.grasp.db` relative to working directory; host binds only 127.0.0.1 port 43821 and validates same-origin write requests. UI has clear saved/pending/error states; runtime recompute only follows committed DB response. Worker jobs superseded by revision cannot update current view.
